# Readiness: what must land before this talk is delivered

The owner decided (2026-09-30) to write this talk for the date when **profile → generate**
and the **safe profile** have shipped, and to deliver it only after that. This file lists
every dependency, which slides and demos wait on it, and how readiness is checked.

**Go/no-go check:**

```bash
REQUIRE_READY=1 PY=~/.venvs/shape/bin/python bash docs/talks/shape-v1/verify_snippets.sh
```

It must exit 0 (every item READY, and every runnable snippet asserted). On 2026-09-30 it
exits 1, with 10 items pending. That is expected.

In `SCRIPT.md` and `DEMO.md`, anything that waits on an item here is marked
**⟦PENDING Rn⟧**. Before delivery, every such marker must be resolved: the snippet run and
its output pasted from a real run, or the slide cut.

## Before delivery: resolve each marker

For every **⟦PENDING Rn⟧** in `SCRIPT.md` and `DEMO.md`:

1. Confirm Rn is READY in the script.
2. Replace the snippet with the **shipped** syntax. The forms in this draft come from the
   plan's text, and flags may differ.
3. Run it, paste the real output, and add its assertion to part 1 of `verify_snippets.sh`.
4. Replace every "TBD" number with the committed value, and add it to `NUMBERS.md` with
   its source and machine.
5. Delete the marker.

If an item is not READY by the date: cut its slides (cut lines in `OUTLINE.md`), or move
the talk. **Don't present a pending item as working.**
