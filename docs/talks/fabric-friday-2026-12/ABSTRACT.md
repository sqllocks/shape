# Ship the Shape, Not the Data: Realistic Dev Data and Data Contracts in Microsoft Fabric

Jonathan Stewart joins Fabric Friday to show how to ship useful data behavior without
copying production rows. We'll profile Lakehouse tables from a notebook, write a data
contract that gates a pipeline load, catch drift before it reaches a dashboard, and
generate a realistic synthetic copy into a dev Lakehouse. Along the way, regex rules
and explicit batch-date bounds catch malformed codes and backdated orders. See what
runs today, where Fabric needs workspace validation, and how to keep the demo moving
with an offline Parquet fallback. All demonstration data is invented and generated by
Shape; statistical similarity is not a privacy guarantee.
