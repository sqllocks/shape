## Deliverables (issue #60 "Wanted" list)

1. **Written stability promise** — `docs/plugins/stability.md`: what is stable in 1.x, what is and
   is not a breaking change, the deprecation process, how a plugin declares its API version, the
   rules for groups added later, and how to run the kit. Linked from `api-v1.md` (generator
   updated), `authoring.md` and `API_STABILITY.md`.
   Tests: `tests/plugins/test_stability_promise.py` (group table equals `GROUPS`; required sections;
   host accepts any 1.x minor and rejects other majors and malformed values; deprecation table
   equals the members whose docstrings say "Deprecated"; links; no non-public names).
2. **Conformance kit per group, and a compatibility test per group in this repo.** The kit
   (`shape.plugins.kit`, one `check_*` per group, `python -m shape.plugins.kit DIST`) already existed
   and is unchanged. New: `scripts/plugin_api_compat.py` and the baseline
   `tests/plugins/api_v1_baseline.json` (API 1.0 as shipped); `tests/plugins/test_api_v1_compat.py`
   runs, per group, a baseline comparison and a frozen reference plugin through the live Protocol
   and the live kit (28 parametrized cases), plus meta-tests showing each kind of break fails
   (removed/new-required member, retyped attribute, changed return, renamed/reordered/removed/
   un-defaulted parameter, data-type field rules, removed group, major change).
3. **`shape.behaviors` under the same promise** — the group does not exist on this branch and was
   not created. The "Groups added later" section lists what a new group must add; tests fail until
   the table, baseline, kit check and reference plugin exist for it.
