# AUD-packaging: audit of packaging and installation, status

Branch `lane/AUD-packaging`, started from `build/main-plan` at 5c91ea5 (INT-15 is in it). The area covers
packaging and installation of the core distribution (maturin platform wheel, sdist, and the T-29
pure wheel) and of the seven first-party plugins. Paths: the packaging sections of the
`pyproject.toml` files, include rules, and packaging tests (`tests/release/test_packaging.py`). No
D-xx/T-xx decision, gate or tolerance was touched. No version, dependency or extra was changed, and
nothing was published. §11 and §2.3 were not edited, and `$SPINDLE_ROOT` was not touched.

## Phase 1: how the area was exercised

- Builds: the core sdist (`maturin sdist`), a platform wheel built from that sdist
  (`cp311-abi3-manylinux_2_34_x86_64`, 3 min), the pure wheel (`scripts/build_pure_wheel.py`), and
  each plugin's sdist and wheel (`uv build`).
- Install matrix (scratch script): Python 3.11, 3.12 and 3.13 × pip and uv × platform wheel,
  sdist and pure wheel × no extras and
  `[sign,yaml,pandas,scipy,excel,delta,domains,simulation,kafka,eventhubs,sqlserver,databases]`
  plus the fabric plugin. Each cell ran in a fresh venv, from a scratch directory, with plugin
  wheels from a local find-links folder. Checks in each cell: `shape --help`, `shape --version`,
  `python -m shape --version`, `shape doctor`, `shape plugins list`, `shape plugins doctor`,
  `pip check`, and a probe. The probe loads every `shape.*` entry point (93 without extras, 114
  with), reads package data through `importlib.resources`, checks each `sqllocks-shape*`
  distribution's version against `shape.__version__`, checks for licence files and shipped
  test/doc files, reports the kernel, and times `import shape` (best of 5).
  Python 3.14.0rc2 (uv-managed) was also tried with the platform wheel and all plugins: everything
  loads, with the rust kernel.
- Results: see "Commands and results" below. `import shape` takes 5–10 ms and
  `python -m shape --version` 50–80 ms (T-18 budget 300 ms).
- Contents: every tracked data file under `src/shape` (schemas, pools, statements, the Spark
  notebook, `py.typed`, `_kernel.pyi`) is in both core wheels (`check_shipped_data.py --wheel`
  passes). The domains wheel holds its 7 data files. No wheel ships tests, docs or benchmarks.
  `twine check --strict` passes on all 17 archives, and `check_user_facing.py --wheel` passes on
  every wheel and plugin sdist.

## Findings

1. **high**: the core sdist ships dev files and fails D-13 (#246). `pyproject.toml`
   `[tool.maturin] include` added `tests/`, `docs/` (including `docs/plans/`), `scripts/`,
   `examples/`, `benchmarks/`, `security/`, `.github/`, every root `*.md` (`CLAUDE.md`),
   `Makefile` and `CODEOWNERS` to the sdist. Repro: `maturin sdist -o d && python
   scripts/check_user_facing.py --wheel d/*.tar.gz` exits 1 with 13,654 hits. Expected: build
   inputs and user files only, and a clean scan. **Fixed** in 94cf96a8 (test 214a3793).
2. **high**: `pip install 'sqllocks-shape[fabric]'` is printed by five error messages
   (`src/shape/scale/sinks/fabric.py:36,46`, `src/shape/scale/api.py:266`,
   `src/shape/cli/auth.py:135`, `src/shape/security/credrefs.py:91`) and `docs/SCALE.md:43`, but
   there is no `fabric` extra. pip warns "does not provide the extra" and installs core only.
   T-08 also lists `[dbt]`, `[healthcare]` and `[all]`, which do not exist (#247). **Open**: this
   needs a dependency change (owner / L1 paths), so it is filed only.
3. **medium**: platform wheels statically link Apache-2.0 (`arrow-*`), BSD-2-Clause (`numpy`
   crate), BSL-1.0 (`xxhash-rust`) and Unicode-3.0 (`unicode-ident`) crates without their licence
   texts or notices (#248). Repro: `cargo tree -e normal --format '{p} {l}'`, then
   `unzip -l <wheel> | grep licenses/`. **Fixed** in 2cc6b13b (test 724411f8):
   `THIRD_PARTY_NOTICES_RUST.md` covers all 113 locked crates, is generated by the new
   `scripts/rust_notices.py write`, is checked from `Cargo.lock` alone, and is listed in
   `license-files`. It was verified inside a freshly built platform wheel's
   `dist-info/licenses/`.
4. **medium**: `sqllocks-shape-domains` ships GeoNames-derived `us_zip_locations.arrow`
   without the CC-BY-4.0 attribution that `THIRD_PARTY_NOTICES.md` requires in "any
   distribution" (#250). **Fixed** in 17516908 (test 46f302aa): the plugin carries a copy in
   `license-files` (in its wheel and sdist), and the test fails if the copy drifts.
5. **medium**: the pure `py3-none-any` wheel's METADATA differs from the platform wheel's and the
   sdist's at the same version (#252). It has 3 of 20 extras (so `[kafka]` on the pure wheel
   installs nothing), no `shape.*` entry points, different classifiers, a hard-coded
   `DEMO_REQUIRES`, and a stale docstring. **Open**: `scripts/build_pure_wheel.py` is L1-owned
   (§12.5), so this is filed only. Suggested fix: derive `Requires-Dist`, `Provides-Extra`,
   classifiers and every `[project.entry-points]` group from `pyproject.toml`.
6. **low**: no Trove classifiers on any distribution, and no project URLs on the plugins
   (#254). **Fixed** in 00541730 (test 411248e2): Python 3.11–3.14 (T-06), `3 :: Only`,
   OS Independent and a topic, plus `Typing :: Typed` on core. Every classifier was validated
   against `trove-classifiers`. The plugins gained Homepage, Repository, Issues and Documentation
   URLs.
7. **low**: README relative links (`README.md:3` `](LICENSE)`, `plugins/shape-fabric/README.md:5,7`
   `](../../docs/...)`) are dead on index pages. `docs/INSTALL.md` says Python 3.11–3.13
   (T-06: 3.11–3.14), and its offline-lock extras list omits `postgres`, `mysql`, `databases` and
   `delta-fallback` (#255). **Open**: README/docs content is outside this lane's paths.
8. **info**: the version is `0.9.0`, while T-10 says `0.9.0.devN` until G8. Version numbers are
   an owner decision, so nothing was changed or filed.
9. **info**: the pure wheel and the sdist also carry `THIRD_PARTY_NOTICES_RUST.md` (it comes from
   the shared `license-files`). This is harmless: it only adds notices.

Improvements (not defects):
- 3badb8a9: one test pins `shape.__version__`, the kernel crate version, every plugin version,
  core's plugin extras and the plugin-to-plugin pins (fabric → eventhubs, sqlserver,
  `sqllocks-shape[azure]`) to the core version. Before, `check_plugin_skeletons.py` checked only
  each plugin's own version and core pin.

Not defects (checked): the plugins' `testing.py` modules ship on purpose. They are documented
public fakes (`docs/plugins/streaming.md`, `docs/plugins/sqlserver.md`, the plugin READMEs). The
pure wheel lacks entry points, but every built-in still loads through `register_builtins`, which
the matrix confirms (`plugins doctor` passes on the pure wheel).
