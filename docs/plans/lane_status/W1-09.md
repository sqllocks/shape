## Item 1: Fabric helper path (done)

`tests/demo/fabric/fabric_helpers.py` replaced `/lakehouse/default` with `str(lakehouse)`. On Windows
that inserts backslashes into notebook source, where they become string escapes. The substitution now
lives in `fabric_source()` and uses `lakehouse.as_posix()`.

Regression test: `tests/demo/fabric/test_fabric_helpers.py` substitutes a `PureWindowsPath`
(`C:\Users\ci\lakehouse`) and asserts `C:/Users/ci/lakehouse/Files/x` with no backslash. It runs on
Linux. Verified red with `str(lakehouse)` (assertion failed on the backslash path) and green with the fix.
I could not run the Fabric demo tests on Windows; the test checks the path text only.
