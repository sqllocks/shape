## P7-02: k-anonymity and suppression

Status: built, checks below run in this session.

What changed
- `src/shape/privacy/cells.py` (new, strict): the minimum-cohort rule. A released cell (a category
  of a value count or enum, a histogram bin, a top-value entry) is absent or stands for at least
  `k` rows. Proportions (stored to six places) become counts through the lower bound
  `ceil(p*base - 5e-7*base)` over the column's non-null rows; the bound is exact up to 1M rows and
  conservative above.
  - categories below `k` fold into `__OTHER__`; if `__OTHER__` is itself below `k` the smallest
    survivors join it (complementary suppression); a column below `k` rows releases nothing;
  - histogram bins below `k` are zeroed and proportion histograms renormalized; no bin left drops
    the histogram;
  - value lists with no counts cannot be checked and are removed.
- Wired into the safe profile (categorical weights, hour/dow/temporal bins, routed histogram),
  `release_for` (uses `minimum_cohort`) and `suppress_shape` (uses `suppress_topk_below`).
  `release.py` rewritten strict and removed from the mypy ratchet list.
- New safe-profile column field and manifest key `cells_suppressed`; parity harness lists it as
  a product-only key (`ADDED_KEYS`) and compares every other key.
- Tests: `tests/privacy/test_cells.py`: hypothesis properties on weights, counts and bins (counts
  up to 2.5M rows to cross the rounding limit), an end-to-end property that builds CSVs, profiles
  them, exports the safe profile and audits every released cell (labels, hashed keys, histogram
  bins, hour, weekday, month) against the raw rows, release-surface properties, and unit cases.
  Mutation check: disabling the absorb step or the bin check makes 2 and 5 of them fail.
- Docs: `docs/PRIVACY_MODEL.md`.

Differences from the baseline, all stricter (the D2 parity run is unchanged by them)
- cell counts use the non-null base (the baseline uses all rows, which over-counts a column with
  nulls); `__OTHER__` is held to `k` too (the baseline can release a smaller residual bucket).
- A property run found one real defect while building this: with 2,000,000 rows a 1-row category's
  weight rounds to 0.0, so the `__OTHER__` bucket carries no mass. That is now stated in the test
  (a zero-weight bucket releases nothing) rather than hidden.
