## 2. The fix: portable math

numpy's float64 `log`, `exp`, `log1p`, `power` and `cos` use AVX-512 routines on some x86 CPUs and
the C library elsewhere; the C libraries of Linux, macOS and Windows differ in the last bit too,
and Rust's `f64::ln`/`exp`/`cos` call the C library. `np.interp` is C code that a compiler may fuse
into a multiply-add on arm64.

- `src/shape/kernel/reference/pmath.py`: numpy twin, IEEE basic operations only (fdlibm `e_log.c`,
  `e_exp.c`, `k_sin.c`, `k_cos.c`, constants by bit pattern): `log`, `exp`, `pow` (exact for y = 1,
  2, 0.5, -1, else `exp(y log x)`), `cos_turns` (cos of 2 pi t, reduced exactly in turns),
  `log1p` (Kahan), `lgamma` (Stirling from 8), `interp` (slope and line as separate operations),
  `exp_scalar`; kernel functions `pm_log`, `pm_exp`, `pm_pow`, `pm_cos_turns`.
- `rust/shape-kernel/src/gen/pmath.rs`: the same operations in the same order; `pm_*`
  pyfunctions (rayon, independent elements); `philox_normal` and the temporal `erf` use them.
- `src/shape/kernel/pmath.py`: front end through the selected kernel (twin below 64 elements).
- Call sites switched: every distribution family's draw and table (`families.py`, the
  `shape.distributions` entries), `empirical`'s interpolation, `RowStream.normal` /
  `normal_from_raw`, `derived` lead times, Zipf/Pareto parent indices (`_relational.py`), fan-out
  weights, `generate_fk_indices`, and spec parameters computed from DDL, a profile (`learn`) or a
  drift plan.
- The statistical distributions are unchanged; values move in the last bits only. The Rust and
  numpy kernels now agree bit for bit on `philox_normal` and `hour_weights_peaks`
  (`tests/kernel/test_gen_kernel.py` tightened from `allclose` to byte equality).

Tests first: `tests/generation/test_w8_04b_cross_cpu.py` failed before the call-site switch (the
AVX-512-off child gave different ids for the 7 families; the tripwire listed 18 call sites in
`families.py` and `numeric.py`); `tests/kernel/test_pmath.py` (constants; log and exp within 1 ulp
of the C library; accuracy of the rest; native == twin bit for bit; a known-answer digest in both
kernel modes and with AVX-512 off).
