## Decisions I made where the issue is silent (please review)

- Rolling window: `shape diff` reports only changes present against **every** run in the window.
- Entry date = `business_date` metadata, else UTC commit date; reference date = `--baseline-date`
  (default today UTC). `previous_run` = newest commit. Under-filled window uses what exists.
- `observe` gates still run and report; only the exit code ignores them. Report JSON keeps `passed`
  (raw) and adds `enforced_passed`.
- Source choice: `--source`, else the only source, else the one named like the profile, else a
  stderr note and no source settings applied.
- `--ignore` replaces the file's ignore lists; `--policy FILE` replaces the file's policy whole.
- "CI outputs": no separate CI-output feature exists, so I took it as the `--json` results and the
  `verify -o` reports, which now carry a `project` block (and per-gate `mode`).
- Discovery stops at a repository root; an invalid discovered `shape.yml` stops the command (exit 2);
  `--no-project` skips it.
