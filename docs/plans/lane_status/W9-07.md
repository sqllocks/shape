## Implementation and compatibility

All opt-ins use supported delta-rs APIs: `DeltaTable.create(configuration=...)`,
`alter.set_table_properties`, `alter.add_constraint`, `alter.add_feature`, and
native generated-column metadata/validation. No new transaction-log writer was
introduced. The existing fingerprint implementation is reused unchanged.

Requested constraints and generated expressions are preflighted against pending
batches before destination mutation. New constraints also check existing rows.
Constraints are committed after the first data commit. Existing rules continue to
apply when options are omitted; failures name their rules/columns and suppress
native bodies and exception chains. Nonnullable Arrow declarations containing
NULL get named `not_null_<column>` errors, including in micro-batch mode, before
committing. Default cloud writes make no additional metadata/network request;
metadata is inspected only after a native failure for safe named diagnostics.

Native `deltalake.QueryBuilder` readback verifies all values in real mapped and
DV-enabled local tables. Its Arrow `string_view` output is normalized to the
logical Delta schema for the strict schema assertion, with raw values asserted
before normalization. The native PyArrow scanner's existing limitations remain
handled by W2-03's DuckDB fallback. The current readback fix uses
`Table.column_names` instead of the nonexistent `Table.names` when restoring the
logical schema; both mapped and DV feature round trips exercise the repair.

Capability refusals name the option, installed version and required public API,
with **1.6.6** identified as the first verified feature release. Opt-ins require
a stable verified release at least that new; default writes retain the published
`deltalake>=0.17` floor. Missing APIs at the same verified
version are also tested. Dry-run reports the combined minimum protocol/feature
union using existing `--sink-config` flags; doctor reports actual versions,
explicit feature lists and implied legacy features. No CLI snapshot changed.
