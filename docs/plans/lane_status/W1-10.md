## Decisions to confirm

- **Which commands are stable.** I made the core workflow and its supporting commands stable (24,
  listed in `CLI_STABILITY.md`) and everything else experimental, including `fidelity`, `chaos`, `emit`,
  `bridge` and `demo`. Promote one by adding it to `STABLE` and the table; the baseline then needs
  `--write`.
- **Deprecation window.** As issue #88 says: at least one minor release, then removal in a minor is
  allowed for a deprecated item. (Plugin API v1 keeps deprecated members until the next major; the two
  promises differ on purpose and each says so.)
- `--json` keys are promised but not snapshot-checked (W1-14); `CLI_STABILITY.md` says so.
- No helper that prints the deprecation warning was added (nothing is deprecated; it would be code
  with no caller). The first deprecation adds it.
