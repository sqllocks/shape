## Early entry point for P5-01 (published)

`shape.chaos.inject_anomalies(batch, *, fraction, seed, kinds=None, protect=())`, documented in
`docs/CHAOS.md` ("Stable entry point"). Schema- and row-count-preserving; returns the mutated
batch plus the changed rows, kinds and columns; deterministic per `(batch, fraction, seed)`;
`protect` keeps the stream key and event-time columns intact. P5-01 derives one seed per batch.
Tests: `tests/chaos/test_anomaly.py`.

Note for P5-01: the baseline's `stream` command never calls its chaos package for
`--anomaly-fraction` (it has its own point-anomaly generator), so this entry point is Shape's own
design over the value category's schema-preserving kinds, not a port.
