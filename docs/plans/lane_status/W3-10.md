## Deliverables (issue #73)

1. **Reconciliation** (`src/shape/quality/reconcile.py`): row counts per table and partition, aggregates (`sum`,
   `mean`, `min`, `max`, `count`, `count_distinct`) per key or over the whole table, keys on one side only, with
   `abs`/`rel` tolerances (`count_tolerance` for counts, per-aggregate override). Both sides are read through
   `load_table`, or are `{"table": name}` of the verified data.
2. **Time-series quality** (`src/shape/quality/timeseries.py`): gaps in a regular series (`every`, `by`,
   `max_missing`), stuck values (`max_run`), daylight-saving transitions with an explicit `time_zone` (zoneinfo):
   rows at local times that do not exist, and the repeated local hour (`fall_back` `repeat` or `once`); the
   skipped hour is not counted as a gap for naive local times.
3. **Both as checks**: gates `reconciliation` and `timeseries_quality` run by `shape verify --config`
   (`reconcile`, `timeseries` keys of `shape-verify-config`, version unchanged, bad rules refused with exit 2);
   additive optional contract v1 rules `timeseries` and `reconcile` checked by `shape.check(profile, contract,
   data=...)` and `shape check PROFILE CONTRACT --data DATA` (a contract with such rules and no data raises
   `ContractError`, exit 2; an older reader refuses them as unknown keys); Python API `shape.quality.reconcile`,
   `check_timeseries`, `ReconciliationGate`, `TimeSeriesGate`. Docs: `docs/VERIFY.md`, `docs/CLI.md`, `CHANGELOG.md`.

Tests (written first): `tests/quality/test_timeseries.py`, `tests/quality/test_reconcile.py`,
`tests/contracts/test_w3_10_rules.py` (boundaries of every tolerance, nulls, groups, unsorted input, bad rules,
CLI exit codes).

## Decisions inside the package and limits

- Gaps count only distances that are a whole number of steps; off-grid distances and repeated times are warnings.
- Months are not an `every` unit (no fixed length). Time text is read as ISO 8601.
- Contract reconcile violations carry an extra `reconciliation` key (the rule's name).
- `timeseries`/`reconcile` rules are top-level only in a contract.
