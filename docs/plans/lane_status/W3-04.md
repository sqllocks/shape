# W3-04: `shape explain` and notebook display (issue #70)

Status: implemented; checks below.

## Deliverables (issue #70)

1. `shape explain DIFF`: `src/shape/report/explain.py` (`explain()`), CLI wiring in
   `src/shape/cli/main.py`. Deterministic fixed templates, no model, no network. `--json` prints the
   structure (`format` `shape.explain`, `version` 1). Docs: `docs/EXPLAIN.md`, pointers in
   `docs/DRIFT.md` and `docs/CLI.md`.
2. Notebook display: `_repr_html_` and `_repr_markdown_` on `Profile`, `DiffResult`, `CheckResult`
   and the tier-3 `DriftReport`, rendered by `src/shape/report/display.py` (25-row cap, safe values
   only, everything escaped).

## Decisions made inside the package

- `src/shape/explain.py` does not exist: it was deleted by P0-04 (plan 8.1, RM8) and
  `tests/test_removed_modules.py` requires `shape.explain` to raise `ModuleNotFoundError`. The code
  lives in `shape.report.explain`, and a test keeps `shape.explain` unimportable. RM8 (`TypeError`
  on a `None` `distinct_estimate`) concerned the deleted module and does not apply.
- Classified columns: withheld when named (`--classified`) or when the safe-profile redaction
  manifest marks them pattern-only or sensitive in a profile passed as `--baseline`/`--current`.
  Range, new-category, category-shift and pattern changes never print values for any column.
- `shape explain` takes a diff or drift report as JSON; a diff file alone cannot say which columns
  are classified, so the value-free rules are the default-deny.
