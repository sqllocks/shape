  stage timings below are the decision basis, not the samples alone.

## Changes so far (unverified: parity and suite runs are in progress)
- `profile.py`: `_clean` returns plain dicts/lists (and NaN-free numbers) without a per-entry walk;
  the tables of a multi-table profile are read concurrently.
- `table.py`: float columns are scheduled first (they carry the longest fit).
- `readers.py`: `_refine_integers` tests the first 4096 values before a whole column; `date32` CSV
  columns become text on the kernel (parallel over chunks), pyarrow cast as the fallback.
- Kernel (`exact.rs` + Python twins in `kernel/reference/exact.py`): `float_repr` (Python `repr`),
  `round6` (Python `round(x, 6)`), `date_iso`. Differential tests in `tests/kernel/test_exact_kernel.py`
  (fuzzed, bitwise): 61 passed.
