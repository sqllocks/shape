## What was built
- `profile.py`: `_clean` returns plain str/int/bool and NaN-free numeric dicts/lists without a per-entry walk
  (`_no_nan`: types checked in C, NaN detected through a sum); the tables of a multi-table profile are read
  concurrently (`_load_tables`, errors in table order).
- `table.py`: float columns are scheduled first (scheduling only, results unchanged).
- `readers.py`: `_refine_integers` tests the first 4096 values before a whole column; `date32` columns become
  text through the kernel (parallel over chunks; pyarrow's cast as fallback for years outside 0000-9999 and for times).
- Kernel (`rust/shape-kernel/src/exact.rs`, twins in `src/shape/kernel/reference/exact.py`): `float_repr`
  (Python `repr(float)`, ties resolved as Python does), `round6` (Python `round(x, 6)`), `date_iso`.
  `column.py` uses them for the top-value keys and weights. `fit.rs` untouched.
- Tests: `tests/kernel/test_exact_kernel.py` fuzzes all three against the Python twins (bitwise for `round6`,
  random bit patterns, ties, infinities, NaN, -0.0): 61 passed.
- The reader's other per-token emulation (`_chunk_label`, `_mixed_chunk_columns`, `_refine_integers`' int re-read)
  costs about 0.002 s on D4 and the EDGE-free datasets (measured), so it was left as is; it only runs on
  mixed-type or whole-number-float columns.
