## Blocking question

Wanted 3 requires Arrow `decimal128(p,s)` to map to `NUMERIC(p,s)` when
`p - s <= 29` and `s <= 9`, otherwise `BIGNUMERIC(p,s)` when
`p - s <= 38` and `s <= 38`. Those tests include legal Arrow types that BigQuery cannot
create using the required unchanged precision and scale.

Evidence, verified locally with Python 3.11 and PyArrow:

| Arrow type | Wanted NUMERIC inequalities | BigQuery legality |
|---|---|---|
| decimal128(10,-1) | 11 <= 29; -1 <= 9 | Invalid: negative scale |
| decimal128(2,3) | -1 <= 29; 3 <= 9 | Invalid: precision below scale |

The [official Google parameterized-decimal documentation](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/data-types#parameterized_decimal_type)
requires NUMERIC scale `0 <= S <= 9` and precision `max(1,S) <= P <= S+29`;
BIGNUMERIC requires `0 <= S <= 38` and `max(1,S) <= P <= S+38`.
Both counterexamples are also invalid BIGNUMERIC definitions. A fake accepting those DDL
strings would conceal the actual service incompatibility.

**Question:** may Wanted 3 add BigQuery's native `0 <= s <= p` condition and refuse unsupported
Arrow precision/scale combinations before a connection, naming the column?

Options:

1. **Recommended:** add the native condition, refuse negative scales and scales above precision
   before connecting, and retain unchanged precision/scale for accepted types. Add dedicated
   negative and boundary tests; document these native restrictions.
2. Permit explicit canonical widening/rescaling, such as `(10,-1)` to `(11,0)` and `(2,3)` to
   `(3,3)`, preserving numeric values but changing declared precision/scale. This changes the
   Wanted mapping and requires an explicit owner decision plus metadata/round-trip rules.
3. Keep the literal specification unchanged. The package cannot be completed because BigQuery
   rejects the required DDL.

No decision has been assumed. Per the session's stop-package instruction, partial implementation
and tests remain local and are not shipped as a completed feature. This pushed journal alone
records the blocker. W9-14 and W9-15 continue independently.
