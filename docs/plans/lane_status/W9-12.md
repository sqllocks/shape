## Implementation and compatibility

Table `measures` and dataset `roles` are additive in the existing `.shape` profile format/version;
old profiles without them remain readable. The existing `shape-dax-answers` format/version 1
continues unchanged. Unsupported DAX is preserved in `.bim` and listed under `skipped` rather
than executed or replaced with invented answers. Direct aggregates can reference any profiled
table, independently of the measure's home table. Native DAX handles role filters and relationships;
Shape does not parse/reimplement RLS. Role names containing XMLA connection delimiters are refused.

The generic optional source `profile_metadata` hook lives in `src/shape/api.py` and attaches hidden
metadata after profiling. The reference profiler directory is byte-for-byte unchanged:
`git diff --exit-code faba6633 -- src/shape/profile/reference` exited 0. Numeric drift thresholds
are unchanged; measure/role records score zero and the numeric drift gate explicitly excludes them.
