## What was built

1. **Scorecards** — `src/shape/quality/scorecard.py`.
   - Six dimension names (`DIMENSIONS`); `GATE_DIMENSION` maps each existing gate to exactly one
     (documented table in `docs/SCORECARD.md`; a test keeps code and doc equal and checks that every
     registered gate and every dimension is covered). No new checks: scores come from the verify
     gates.
   - Score = mean of checks; a row-level check scores `100 * (1 - failing / rows)`, any other gate
     is 100 or 0.
   - Owners: `column_owners(project_dir)` returns `None` when no `shape.yml` exists, else the
     `owners` mapping (`"table.column": owner`).
   - Trends: `record_scorecard` / `scorecard_trend` over `LocalRegistry` history (names
     `scorecard-<name>`; scores only, no samples are stored).
   - Snooze and suppress: versioned file `format: shape-scorecard-suppressions`, integer `version`
     (1); newer version refused; snooze needs `until`, a reason is always required; hidden checks
     are listed under `known_issues`.
2. **Row-level output** — `src/shape/quality/rowlevel.py`: failing rows for nulls, repeated keys,
   orphan foreign keys, numeric ranges, and temporal range/future/ordering; samples that redact
   classified columns by default (declared, name-like, or value-pattern via
   `shape.privacy.detect`); an optional flag column (`--flag-output`). `quarantine.py` is not
   touched.
3. **Output and CLI** — `shape scorecard` (`src/shape/cli/scorecard.py`, registered in
   `cli/main.py`), `--json` and Markdown, `-o`; docs in `docs/SCORECARD.md`, cross-reference in
   `docs/VERIFY.md`.

Tests (written first): `tests/quality/test_rowlevel.py`, `test_scorecard.py`,
`test_scorecard_cli.py`, fixtures `tests/quality/fixtures/` (`gates.json`, `suppressions_v1.json`
as the v1 compatibility fixture).

## Dependency and decisions to note

- **W1-04 (`shape.yml`) has not landed.** Owners are read only through `column_owners()`; I assumed
  an `owners:` mapping in `shape.yml`. When W1-04 fixes the project file layout, only that function
  needs to change (the docs say the project file format is owned by `shape init`).
- A dimension whose every check is hidden as a known issue has no score (`null`), rather than 100.
- `temporal_consistency` maps wholly to timeliness (including start/end ordering), keeping the
  mapping one gate to one dimension.
- Samples show only the columns a check looked at (never the rest of the row) and use 0-based rows.
- `--show-classified` is the explicit opt-out of safe sampling; `--record` never stores samples.
- The command reports and exits 0; it adds no pass/fail threshold (not on the list).
- The persisted-format compatibility policy (W1-01) has not landed; both formats declare `format`
  and an integer `version`, and refuse a newer version.
