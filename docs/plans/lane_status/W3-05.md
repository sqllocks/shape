## Interpretations (please confirm)

* `report_card` has one keyword-only argument beyond the issue's signature, `require`, so the `--require` verdict is in the card (`overall`, `overall_reasons`) and a missing scikit-learn can be exit 2 for `utility`.
* "Up to `max_rows`" reads `memorization.max_rows` (default 5000); the issue names no `privacy.max_rows`.
* `--require S` fails when section S is `not_run` **or any of its tests was not run**. The privacy section is never wholly `not_run` (the memorization gate always runs), so `--require privacy` would otherwise never fail when `--holdout` is missing.
* The membership test is `not_run` for a table with fewer than 10 rows on a side, no shared numeric column, or no holdout table of that name.
* `--tiers` accepts 1 and 2 only (tier 3 is experimental); tier 1 and 2 cards carry summaries without the mixture, conditional and temporal numbers, which could hold data statistics.
* No `--input-format` flag (not in the Wanted list).
