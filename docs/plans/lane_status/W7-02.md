## Blocked: `stream` / `emit` with a missing OneLake item

The missing-item error is a `FileNotFoundError` (as the issue specifies), which is an `OSError`.
`src/shape/streaming/emit/runtime.py` `_send` retries every `OSError` and then raises
`ShapeError("delivery failed after N retries: <message>")`, so the line is not the whole message and
three retries are wasted. That file is outside this package. Proposed fix for the lead or an audit
lane (in `_send`): re-raise `FileNotFoundError` and `PermissionError` immediately instead of retrying
(`except (FileNotFoundError, PermissionError): raise` before the existing clause). Once that lands,
drop the `"does not exist"` filter in `CLI_RUNS` in the test file; the test already asserts the exact
line.
