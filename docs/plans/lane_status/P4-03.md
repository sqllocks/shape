## P4-03 — Rust generation kernel

Contract: `docs/GENERATION_KERNEL.md`. Code: `rust/shape-kernel/src/gen/{rng,alias,strings,temporal,mod}.rs`; twin `src/shape/kernel/reference/gen.py`; stubs in `src/shape/_kernel.pyi`.

- **Philox4x64-10** (`rng.rs`): block `c` of a stream is the cipher on counter `c + 1` (numpy increments before it generates); verified against `numpy.random.Philox(...).random_raw()` for four keys, blocks 0, 1, 7, 1000, 2^20+3, every `per_row` 1..7 and unaligned starts. Results are independent of how the rows are split into calls or threads (tests split at 1, 4095, 8192, 65,537, 150,000 and run 400k-row calls on all cores).
- **Alias sampling** (`alias.rs`): Vose's method, identical to the twin bit for bit (hypothesis property test, mass conservation); a draw uses two words.
- **Pool and string assembly** (`strings.rs`): `pool_take`, `template_strings` (literals, column slots with zero padding, string and int64 columns), `join_strings`, `string_case` (upper, lower, title), `uuid4_strings`, `random_strings`.
- **Temporal sampling** (`temporal.rs`): `day_weights` (month and day-of-week profiles, each (month, weekday) pair carrying its own weight), `hour_weights_peaks` (bimodal and general Gaussian peaks, own erf series so both implementations agree), `temporal_sample` (day, hour, offset inside the hour; microsecond or whole-second).
- **Differential tests**: `tests/kernel/test_gen_kernel.py` (30 tests): Rust against the twin on every function; integer and string results equal, `philox_normal` and `hour_weights_peaks` to 1e-12 relative (different libm). Error cases raise `ValueError` in both.
- **Microbenchmarks** recorded in `benchmarks/vs_spindle/results.json` under `kernel_microbench` (schema extended; `run.py` keeps the key). Script: `benchmarks/vs_spindle/kernel_bench.py`; equivalence of each kernel with its twin is checked on the timed output before any time is recorded.

Fixes: G1 (the plan lists it against P4-03: the seed is now part of the stream key, never added to the row index; a negative or large seed gives a different, valid stream: see `tests/generation/test_gen_rng.py`; the address pack's own `_u64` is replaced when P4-04b ports it).
