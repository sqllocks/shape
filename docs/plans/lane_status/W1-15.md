## Decisions and findings

- **One flat name map.** A strategy and a distribution may share a name (`uniform`, `normal`); a
  pin applies to both. A test requires built-ins that share a name to have the same version.
- **Only the `distribution` strategy names a distribution.** Other strategies that take a
  `distribution` key have their own algorithm, covered by their own version. The `distribution`
  strategy resolves the family exactly as it samples (`resolve_distribution`).
- **`shape pin` never moves an existing pin** (moving it would change the data) and does not
  rewrite a spec with nothing to add.
- **Error label.** `shape generate` and `shape pin` name the spec file in the message
  (`shape: error: s.json pins ...`). Python API, `pack run` and `pack replay` say "the spec",
  because the engine has no path. `pack run` raises out of the runner so the exit code is 2.
- **Change to W1-03's test:** `tests/scenario/test_reproducibility.py::test_a_run_records_the_tuple_and_the_dataset_id`
  asserted the manifest's `reproducibility` keys are exactly the seven; it now also allows
  `generators` (the field is additive; nothing was loosened otherwise). No W1-03 or W1-06 source
  was changed beyond what the deliverables need: the loader schema, `GenSchema`, `SpecDocument`, the
  published schema file and the manifest builder, runner and replay gained the new field.
- **Published schema file regenerated** (`python -m shape.generation.spec_schema`). The file in the
  base was stale: it lacked `conditional_table`, `hierarchy` and `hierarchy_field`, so five W1-06
  schema tests failed before this lane; regenerating fixed them. If the lead regenerates it too, a
  merge conflict in that file is resolved by regenerating.
- `docs/plugins/stability.md` (W1-05) is not in this base, so the optional `generator_version` is
  documented in `docs/plugins/authoring.md` and `docs/GENERATION_STRATEGIES.md`; move the paragraph
  when W1-05 lands. `docs/plugins/api-v1.md` is generated from the Protocols and is unchanged:
  `generator_version` is deliberately not in a Protocol (a runtime-checkable Protocol would make
  it required).
- The W1-01 time-capsule corpus is not in this base, so `expected.json` and the `generators` map
  are covered by their own format/version tests, not registered there.
