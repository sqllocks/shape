## Finding for the lead (Delta)
The new regression test failed on the first run: with `deltalake` 1.6.6, a time-zone-less timestamp column makes the
writer add the `timestampNtz` feature (reader 3 / writer 7). To meet the issue, `DeltaSink` now writes such columns
as UTC timestamps (wall-clock value kept, read as UTC), at any nesting depth. This is a behaviour change for
Delta output of naive timestamps (they read back time-zone-aware). Decision for the lead if a different mapping is wanted.
