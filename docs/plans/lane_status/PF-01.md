## PF-05 — Container image: built in CI only; not verified by a real image build here

- `Dockerfile` (two stages): build stage builds the Rust wheel with maturin from `pyproject.toml`,
  `README.md`, `LICENSE`, `THIRD_PARTY_NOTICES.md`, `rust/`, `src/`; runtime stage is
  `python:3.11-slim`, installs the wheel with `[azure]` through a BuildKit bind mount (no
  wheel layer), removes Arrow Flight, headers and test suites, byte-compiles `shape`, fails the
  build if an import the CLI needs is gone, runs as user `shape` (uid 10001), workdir `/work`,
  no ENTRYPOINT (`docker run … shape profile …` is the whole command line). `.dockerignore`.
- `.github/workflows/container.yml`: `build` (on PRs/pushes touching its inputs): builds the
  image, **fails if the image is 500 MB or more**, checks non-root + `adlfs`/`azure.identity`/
  `deltalake` + the Rust kernel, then generates D1 and runs `shape profile` on both
  `d1.parquet` and `d1.csv` mounted read-only from the host; `publish`: GHCR with version tags
  and a provenance attestation, **only on `v*` tags** (none created here).
- `docs/CONTAINER.md`; `tests/integrations/test_container.py` (10 static tests, passed).
- **What I could and could not check here (no Docker daemon):**
  - Built the wheel from a copy of *only* the files the Dockerfile COPYs: succeeded (maturin, 1m52s),
    so the COPY set is sufficient.
  - Replayed the runtime RUN recipe in a fresh venv (same install, trims, compileall, import
    check): `imports ok`; then `shape profile` on D1 parquet and CSV from a read-only
    directory: exit 0 both times, 0.68 s for the parquet profile.
  - Size: site-packages after the trims is 381 MB; minus the venv's pip and setuptools (26 MB,
    which the base image already has) is about 355 MB. python:3.11-slim is about 125–130 MB by my
    recollection (not measured), so **my estimate is about 480–485 MB, a thin margin under 500 MB.**
    The CI gate is the real check; if it fails, deltalake 1.6 (133 MB, already stripped) and
    pyarrow (106 MB after trims) dominate, and pinning an older `deltalake` in the image is the
    next lever.
  - **Not run:** `docker build`, `docker run`, the size check, the publish job. PF-05's
    acceptance ("CI builds the image; D1 profile exits 0 in it; under 500 MB") is therefore
    **unproven until `container.yml` runs on a runner with Docker.**
