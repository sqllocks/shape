## The rule
A column is an enum only if, besides the existing size limits (`card < 200` or `ratio < 0.30 and card < 50_000`),
`card > 0`, **distinct <= 0.5 x non-null values**, and it is not unique. Written as `2 * card <= n_nn` (integers, no
float edge). Uniqueness is implied (unique means distinct == non-null, which is above half for any non-empty column),
and is also tested explicitly where `is_unique` exists. Same rule, same arguments, in:

| place | change |
|---|---|
| `src/shape/profile/reference/column.py` | both paths (`_profile_object_column`, `profile_column`); `n_nn` is the non-null count |
| `src/shape/kernel/reference/exact.py` `_need_for(card, top_n, row_count, n_nn)` | `n_nn = len(values)` (the kernel receives non-null, non-NaN values) |
| `rust/shape-kernel/src/exact.rs` `need_for(.., n_nn)` | same; public signatures of `count_numeric` unchanged |
| `plugins/shape-sqlserver/.../profiler.py` | existing limits (50 distinct or < 5% of sampled rows) AND `card <= 0.5 x len(present)` (sampled non-null) AND not `is_unique` |

**Bounded mode: there is no enum rule to change.** `profile/engine.py` and the Rust bounded tracker
(`rust/shape-kernel/src/profile.rs`, SpaceSaving/HLL/KLL) emit `top` lists and `error_models`, never `is_enum` or
`enum_values` (grep of `src/shape/profile/engine.py` and `rust/shape-kernel/src/*.rs`: the only enum rule is `exact.rs`
`need_for`). `test_bounded_mode_has_no_enum_flag_and_exact_mode_agrees` pins this (both modes, both kernels). If the owner
wants an enum flag in the engine document, that is new surface, not this work package.
