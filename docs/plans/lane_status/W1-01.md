## Decisions for the lead

1. **Generation schema writer is not stamped.** `benchmarks/vs_refengine` `ddl_1to1` and `schema_import`
   pin the written file equal to the baseline's and I cannot loosen them. The reader accepts the
   unified keys and `x_` fields. Stamping needs an owner decision on those harnesses.
2. **`ShapeContract.version` is defined as the file's format version** (it was only ever checked to
   be >= 1). A contract's own revision belongs in `metadata`.
