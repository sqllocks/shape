## Design (decisions inside the work package)

- The target is the `.shape` profile (`shape.profile`). Sketch state is the optional
  `sketches.json` component of the `.shape` file (`format` `shape-profile-sketches`, integer
  `version` 1; manifest key `sketches` only when present). The profile body and its content id are
  the same with or without it; a profile written without `--sketches` is byte-identical to before.
- Exact statistics merge from the profiles alone (rows, nulls, NaN/inf counts, min, max, mean, std).
  Cardinality, quantiles and top values merge from the kernel's bounded-mode sketches, which both
  kernels read and write in the same bytes. Statistics that need the whole data (fits, enum,
  patterns, histograms, correlations, keys) are `None` in a merged profile and listed in
  `merge.unavailable`.
- A profile without sketch state merges only with `exact_only=True` / `--exact-only`; otherwise
  `MergeError` names the input and the statistics that need sketches.

- `tests/demo/fabric` and `tests/demo/content` were not run (need `nbformat`/unixODBC and the
  fabric requirements; same ignores as `make check`). `cargo fmt/clippy/test` not run: no Rust
  changes. The `make check` coverage and heavy-marker runs were not repeated; the plain
  `-m "not emulator and not live"` run above covers them functionally.
- `scripts/check_secrets.py` lists `plugins/shape-fabric/tests/test_recorded.py`; it does so on the
  base branch too (not caused by this work).
- Sketches are not kept for `.xlsx` workbooks (clear `SourceError`). Sketches of inputs whose Arrow
  column types differ cannot combine (clear `MergeError`; exact statistics still merge with
  `--exact-only`). `shape profile export` does not carry sketch state. `--sketches` re-reads the
  source with the plain reader, so a cloud `--auth` source is not covered by the credential
  context (untested; not part of the Wanted list).
- Inputs profiled by different kernels differ only in the last bits of float moments and fitted
  parameters (existing behaviour); merging the same inputs is identical in both kernels (tested).
