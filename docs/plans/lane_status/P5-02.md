## Acceptance, item by item

1. **Contract tests (each emitter honours the runtime's contract).** Run, passing, on every PR
   (`-m "not emulator and not live"`): the four contract checks, each driven through the real
   `EmitRunner` + `EmitterSink` + the real plugin emitter over a fake client:
   * *idempotency key*: every message's wire key is `<table>/<seq>` and agrees with its body (flat
     and CloudEvents; CloudEvents `id` equals the key), no duplicate key in a run, a second run
     produces the same keys and bodies, bodies equal the runtime's flat events, and `emit()`
     returns the event count only after the destination holds them;
   * *at-least-once*: injected transient failures are retried by the runtime (`report.retries >= 1`),
     the first event of each key equals the uninterrupted stream; a destination that always fails
     stops the run with an error;
   * *backpressure*: a destination that reports full is waited for inside `emit` (and never costs a
     retry in the runner); the check fails if the destination never reported full (not vacuous);
   * *checkpoint*: after a run that fails, the checkpoint offset never exceeds the keys the
     destination holds; a clean run ends with offset == total and `complete`; a crash (checkpoint
     rewound to a stale offset) restarts, sends repeats, and keep-first-per-key equals the
     uninterrupted stream.
   Files: `tests/streaming/emit/test_emitters.py` (core `file` and `jsonl`, plus console, kit, resume
   and torn-line tests), `plugins/shape-kafka/tests/test_emitter.py`,
   `plugins/shape-eventhubs/tests/test_emitter.py` (also with 3 kB service batches),
   `plugins/shape-fabric/tests/test_eventstream.py`, `test_eventhouse.py` (also with 20 kB requests;
   the Eventhouse takes only `flat`, so it is run with `envelopes=("flat",)`). Each emitter also
   passes `shape.plugins.kit.check_emitter` and `python -m shape.plugins.kit <dist>`. Plugin
   discovery, URI parsing, option checking, missing-library messages, key/property/header contents,
   service-batch splitting, oversize events, busy-service exhaustion, 400/401/403/5xx handling,
   table/mapping creation and type mapping are tested too. `shape emit --sink kafka://...` end to end
   through the CLI over the fake cluster, with a checkpoint and a finished-run rerun.

## Decisions for the lead / things to confirm

* **Live-test gating** is done by the workflow (job and step conditions on the secrets), not by
  `skipif`, to honour "never skip a test". If you prefer an in-test skip, it is a one-line change.
* **Core emitters live in `shape.builtins.emitters`** (not `shape.streaming.emit`), because the
  existing built-in rules (`tests/plugins/test_builtins.py`: installed metadata equals `BUILTINS`,
  docs page lists every built-in) key on that package. `FileSink`/`StdoutSink` stay as the
  runtime's own sinks; `--sink file -o` still uses `FileSink`. `file://` and `jsonl://` emitters are
  reachable as `--sink file:///path.jsonl` / `--sink jsonl:///dir`.
* **Emitter options from the command line**: `shape emit` passes only `envelope` and `resuming` to
  an emitter. Connection strings and tokens come from environment variables, and Kafka `config`
  (SASL/TLS) is available from Python only. P5-04 (`shape stream`, "plus Shape's sinks") should add
  an options-file route; nothing here blocks it.
* **Event Hubs throttling**: azure-eventhub 5.15 has no `ServerBusyError`; the emitter recognises
  throttling by the `server-busy` text of the `EventHubError` (the SDK also retries internally).
  Verified only against the fake (it raises that text), not against the emulator or a live hub.
* **Eventhouse / Kusto emulator**: the streaming-ingestion call shape (`/v1/rest/ingest/<db>/<table>
  ?streamFormat=JSON&mappingName=...`), the mapping command and the `kustainer` image/port are written
  from the documented API and are **unverified against a real engine**; the first nightly run is the
  check, and `fabric-emit-e2e` may need a tweak (for example, image start-up time or whether the
  emulator serves streaming ingestion). The fake-service contract tests cover the emitter's own
  logic.
* Eventhouse does not deduplicate; this is stated in the docs and `dedupe_query` is the reader's
  tool. Idempotent ingestion (`ingest-by` tags) is not available for streaming ingestion.
* The P5-01 test `tests/streaming/emit/test_runtime.py::test_realtime_rate_within_five_percent`
  failed once while the machine was loaded by a parallel run, and passed alone (24 passed in 15 s)
  and in both full suites; it is timing-sensitive and not changed.
