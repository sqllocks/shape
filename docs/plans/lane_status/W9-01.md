- Source v1 registrations: `postgresql`, `postgres` and `mysql`. Catalog Arrow schemas,
  server-side batch cursors, shared credential resolution and TLS defaults; invalid URI,
  missing table and unknown options fail before connection.
- Declared integer widths, decimals, time zones, date/time, boolean, UUID metadata, binary and
  JSON-text types. Unsupported types become text with a column warning. Decimal precision
  outside decimal128's representable range is an explicit named-column error.

  selection, exact declared primary/composite foreign keys and declared relationship evidence.
  Catalog row counts are estimates; distribution statistics describe sampled rows.

  arguments. Existing asynchronous job behavior is preserved; percent-encoded query credential
  keys and empty/whitespace userinfo boundaries are masked before job persistence.

  database bridge artifacts use safe capture. Existing file bridge behavior is preserved.
- Plugin README, CLI, bridge Security and changelog documentation; additive CLI and bridge
  schema snapshots. No core dependency or benchmark harness change.

## Lead CI regression: SQL Server save/load identity

Lead CI on implementation head `9ebeb032` found two SQL Server round-trip failures.
They reproduce in the exact CI Python 3.11 environment: unchanged
`plugins/shape-sqlserver/tests/test_profiler.py` exited 1 with

replaced the population row count with sampled rows for both category support and

and amounts as sensitive, so default safe save removed their extrema. The fix
separates the two counts: sensitivity retains its existing population-based rule;

artifact reader/writer, SQL Server source or SQL Server test changed.
