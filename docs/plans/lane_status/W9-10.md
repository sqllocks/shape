Explicit semantic primary keys override heuristic inference without conflicting
with alternate unique columns; their generic tests are retained. Primary and
matching foreign entities become schema keys. Dimension granularity,
measure expressions and every aggregation are retained in metadata. Expressions
that are SQL rather than a direct column name produce named derived columns;
their SQL is retained without executing it. Unresolved or conflicting entity
references name the declarations and fail explicitly.

Singular tests use the existing contract pattern-label regexp table, inclusive
non-numeric bounds and true rates over non-null booleans. DuckDB execution covers
passing and violating rows, dates, inclusive bounds, nulls, empty tables and rate
bounds zero and one. Generated filenames come from the model, column and rule.
Merge is deterministic and preserves unrelated SQL files.

Report `impact` declares `format: shape-dbt-impact`, integer `version: 1` and sorted
metrics/exposures per column. Legacy version 1 report fields remain readable;
the compatibility test also renders a report without the additive impact field.
Computed measure references are lexed against declared model columns, excluding
SQL literals/comments, function names and unknown identifiers. Singular-test and
model SQL are not parsed. Metric and model dependency walks terminate on cycles.

Composite seed keys emit one entity using length-prefixed string components,
with dialect-specific quoting, casts and length functions. Nullable foreign
components produce NULL. Parent and child components share ordering and entity
names. DuckDB tests distinguish delimiter collisions, empty strings, booleans,
numbers and nullable child tuples. No new dependency was added to core or plugin.

The example's new singular test increases the existing nightly build's exact
expected count from 31 resources/23 tests to 32 resources/24 tests. The test also
asserts that the new singular node is present. No pinned golden or byte corpus was
changed. No tracker, roadmap table, gate or tolerance was changed.
