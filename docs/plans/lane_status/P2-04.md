## What was built

- `src/shape/builtins/` (25 plugins, each subpackage declares `SHAPE_API = "1.0"`):
  - `sources/`, `sinks/`: csv, parquet, jsonl, ipc, over `shape.io.readers` (new public
    `shape.io.file_kind`); the JSONL file connectors of `connectors/files.py` are folded in here.
  - `detectors/`: email, us_ssn, phone, ipv4 (wrap `shape.privacy.detect`).
  - `fitters/`: `auto`, a thin wrapper over `shape.profile.fitting.detect_distribution`: the
    profiler is not changed (numerics and output untouched); a test asserts the fitter returns the
    profiler function's family and parameters.
  - `strategies/`: constant, sequence, choice, uniform, normal, address. `strategies/address.py`
    is `packs/address.py` moved (git mv; still on the mypy ratchet under its new name), plus the
    Arrow-array `address` strategy.
  - `distributions/`: normal, uniform, exponential, lognormal, in the fitter's `loc`/`scale`/`s`
    parameters, keyed Philox streams per `(seed, table, column, chunk)`.
  - `calendars/`: us_federal and us_retail, rule-based (nth/last weekday, Easter computus,
    observed shifts). **Lift is neutral (1.0) unless `holiday_lift` is set**: lift magnitudes,
    ramp and decay are P4-05's; `holidays(start, end)` gives the dates.
  - `catalog.py`: the table of entry points (strings only).
- `pyproject.toml`: `[project.entry-points."shape.*"]` for all 25, and the import-linter contract.
- `src/shape/plugins/registry.py`: `register_builtins(host)` adds any built-in discovery did not
  find; `default_host()` calls it. The only module that imports `shape.builtins`.
- Contract: `source_modules` lists every top-level module except `shape.builtins` (with
  `source_modules = ["shape"]` import-linter reported no violation on a toy tree; a test asserts the
  list is complete and another that the contract fails a stray import). `lint-imports` is in
  `make check` and CI.
- G8: `DomainRegistry.get` orders versions numerically (`_version_key`); regression test
  `test_g8_latest_version_is_numeric_not_lexicographic` failed before the fix (`1.9.0` returned).
- Removed: `connectors/files.py`, `connectors/registry.py` (`ConnectorRegistry`, superseded by the
  plugin host), their tests; regression asserts `ModuleNotFoundError`.
- `shape.privacy.detect` annotated (strict; off the mypy ratchet). Docs: `docs/plugins/builtins.md`,
  `docs/plugins/host.md`.
- `tests/plugins/test_host.py`: its `PluginHost()` calls use `_third_party()` (discovery without
  core's own built-ins) so they still see only the plugins they install.

## Left for others / not done

- `shape plugins list` is P2-03's command. Here `shape plugins doctor --json` lists every built-in
  (test `test_plugins_doctor_reports_every_builtin_ok`) and `default_host().records()` has all 25.
- DB-API, Kafka, Event Hubs connectors and `connectors/qualification.py` stay in `shape.connectors`:
  they need a connection object or broker, not a URI (Phase 6 moves them to plugins).
- `packs/domains.py` and the rest of `packs/` stay (domains are P6-01).
- The distributions use numpy's Philox, not the in-house Rust Philox (P4).
