## Decisions inside the package

- Core holds no cloud SDK (T-18): the credential comes from the `shape-fabric` plugin through
  `shape.cli.auth.make_credential`; a missing plugin is a `fabric.auth` fail line, not a traceback.
  OneLake is asked about the item with one HTTPS call using the token (never printed or stored).
- Plain `shape doctor` stays offline; each connectivity check runs only when its option is given.
- Kafka sign-in uses a metadata request through `confluent-kafka` when installed, else a warning.
