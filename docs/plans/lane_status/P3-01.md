## P3-01 — Stream runtime

Fixes: S3.

### What was built
- `src/shape/streaming/runtime.py`: `TumblingProfiler`, `SlidingProfiler`, `SessionProfiler`,
  `GlobalProfiler` (one `WindowedProfiler` base), `WindowProfile`, `restore_profiler`. Micro-batches
  (Arrow record batches) go through the kernel's bounded-mode `ProfileState` (P1-06/P1-07,
  numerics untouched); windows close on the watermark (`max event time - allowed_lateness`, advanced
  at batch boundaries); late rows are counted and dropped or sent to `late_sink`; `snapshot()` is a
  JSON-safe dict and `restore()` rebuilds the profiler. Sliding windows merge `gcd(size, slide)`
  panes; a one-pane window is not merged (it equals the batch profile of its rows).
- Kernel (both kernels, one byte format): `ProfileState.snapshot()` and
  `ProfileState.from_snapshot(schema, bytes)` for bounded mode (`rust/shape-kernel/src/profile.rs`,
  `sketch.rs` accessors, Python twin in `kernel/reference/profile.py`, `_kernel.pyi`). Existing
  numerics are unchanged.
- `profile/engine.py`: `table_entry()` split out of `profile_table` so a window's profile has the
  batch layout. No behavioural change.
- S3: `TumblingWindow.restore()` (`streaming/windows.py`); the module is now strict-typed and off the
  mypy ratchet list.
- `docs/specs/STREAMING_SEMANTICS.md`: Draft 2 (time, windows, watermarks, late data, snapshots).
- Tests: `tests/kernel/test_profile_snapshot.py`, `tests/streaming/test_runtime.py`,
  `tests/streaming/test_windows.py` (S3 regression: fails on the old code).

### Notes for the lead
- The two kernels add floating-point moments in different orders (Rust per row, the Python twin per
  batch), so equal input does not give equal snapshot *bytes* across kernels. Each kernel reads the
  other's snapshot, and a restored state continues exactly like an uninterrupted one in the same
  kernel (tests cut on batch boundaries for that reason).
- Gate G3 evidence in the test suite: `test_replay_of_d2_in_bounded_mode_equals_batch_bounded_profiling`
  (D2 generator at 60,000 rows, micro-batches of uneven size, bounded stream replay equals bounded batch
  profile, top values and quantiles equal, error models equal) and
  `test_results_are_identical_across_processes` (`PYTHONHASHSEED` 0, 1, random; both kernels).
