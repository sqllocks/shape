## Decisions where the issue is silent (please review)

- `--scaled`: absolute difference of each table's share of total rows against `--row-tolerance`
  (a relative difference fails the retail domain, whose dimension tables are fixed size).
- Absolute mode: `|B - A| / A` (an empty A passes only an empty B).
- Distribution check = the drift engine's column comparison, minus: fitted-family name flips,
  unseen categories under the `category_tvd` share, `new_categorical_values` on id-like columns;
  with `--scaled` also distinct counts and extremes, and id-like columns are `not_measured`.
- `--baseline` does not change the exit code (any failing consumer exits 1); it adds markers.
- A contract that cannot be checked against the profile's shape fails that consumer
  (`contract_not_applicable`) instead of exit 2.
- `--no-project --source NAME` is allowed for `contracts check-consumers` (names the source).
- Added `contracts/consumers` to `shape init`'s folders and `shape.consumers`, `shape.parity` to the
  import-linter source list (a test requires it).
