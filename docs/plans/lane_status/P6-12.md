## Python API for P6-11 (`shape.demo`; plain dicts in and out, JSON-safe)

All take an optional `runtime=DemoRuntime(out=, registry=, manifest_dir=, services=, sink_factory=,
transport=, token=, storage_token=, profile_database=, jobs=)`; the bridge should pass `out=sys.stderr`.
Unusable input raises `DemoError` (a `ValueError`); a missing session `SessionNotFoundError`; a failed
run is a result with `success: false`.

* `demo_list() -> {"scenarios": [{name, description, supported_modes, domains, default_rows, tags}], "count"}`
* `demo_run(params: Mapping | DemoParams, *, runtime=None) -> {success, session_id, scenario, mode,
  fidelity_score, error, artifact_count, [scale_mode], [fabric_run_id, status]}`. The bridge's defaults
  (`rows` 50000, `seed` 42, `output_formats` []) are the bridge's to apply; here `rows` defaults to the scenario's.
* `demo_status(session_id, *, token=None, runtime=None) -> {session_id, manifest, [fabric]}`
* `demo_cleanup(session_id, *, dry_run=False, connection=None, runtime=None) -> {session_id, dry_run, ok,
  removed: {target: [names]}, failed: [{target,name,error}], skipped: [{target,name,reason}]}` (the
  baseline returned only the `removed` map).
* `demo_preflight(connection=None, *, runtime=None) -> {profiles: [{name, checks: [{target,status,message}]}], ok}`
* `demo_init(name, *, workspace_id, warehouse_conn, warehouse_staging_path, eventhouse_uri,
  eventhouse_database, sql_db_conn, lakehouse_id, local_path, auth, tenant_id, client_id, client_secret, runtime)`
* `demo_notebook(scenario, mode="inference", output=None) -> {path, scenario, mode}`
* `demo_report(session_id, fmt="md", output=None, *, runtime=None) -> {session_id, format, content, path}`
