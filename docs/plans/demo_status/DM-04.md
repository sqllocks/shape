## Deviations and findings (details in demo/DRIFT.md)
- The retail schema has no `product.sku`; `make_data.py` derives it from `product_id`.
- File names: `customers`, `orders`, `products`, `returns` (SQL keywords), matching RUNBOOK.md.
- Default `mean_shift_std` (0.5) does not flag a +40% shift (0.43 std): the demo diff needs
  `thresholds={"mean_shift_std": 0.25}`. The Fabric notebook uses defaults unless L2 passes
  thresholds. Contract still fails on `order_total.max`.
- Uniqueness loss is not a diff kind, so `diff` cannot report `products.sku`.
- Profiler side effects (L1 code, not edited): `order_total` reports `new_categorical_values`
  because a float column carries enum values; `products.category_id` `distribution_change`.
