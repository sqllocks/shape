## What was built

- `shape.save(profile, path)` / `shape.load(path)` (`src/shape/profile/reference/profile.py`): a `.shape` zip
  artifact (manifest `format: shape`, `kind: profile`, `format_version: 1`, sha256 content id, verified on
  load). NaN and ±infinity are encoded as `{"$float": "nan"|"inf"|"-inf"}` (P8); bare `NaN`/`Infinity` is never
  written. Key order (value frequency order) is preserved.
- `shape.check(profile, contract)` (`src/shape/contracts/v1.py`): every §12.3 rule (`row_count` min/max,
  `dtype`, `nullable`, `unique` on the exact distinct count, `max_null_rate`, `pattern`, `allowed_values`,
  `min`, `max`, `distribution`, `required_columns`, `allow_extra_columns`). Returns `CheckResult` with
  `passed`, `violations` (`{column, rule, expected, observed}`) and `to_dict()`. Contract may be a dict or a JSON
  path. Unknown keys or rules raise `ContractError` (a `ValueError`): a typo must not silently pass a gate.
  Multi-table profiles need a `tables` object in the contract (an extension; the §12.3 format is single-table).
- `shape.diff(baseline, current, *, thresholds=None)`: the seven §12.3 kinds with the default thresholds and
  severities (`column_added`/`column_removed` high, `dtype_change` high, `null_rate_change` medium,
  `cardinality_change` medium, `mean_shift` medium, `distribution_change` low,
  `new_categorical_values` low). Thresholds: `null_rate`, `cardinality_ratio_max`, `cardinality_ratio_min`,
  `mean_shift_std`, `min_severity`. `drifted` is true when any change at or above `min_severity` (default
  `low`) exists. New categorical values are judged on `enum_values` of enum columns.
- `Profile.to_html()` (`src/shape/report/html.py`): one self-contained document, inline CSS and inline SVG
  only: per-column table, quantile strip, category bars, hour and weekday histograms, patterns, keys,
  relationships. No scripts, links or URLs. Text is HTML-escaped.
- CLI (`src/shape/cli/main.py`): `shape profile SRC -o OUT.shape [--html] [--json] [--spindle-compat]`,
  `shape check PROFILE.shape CONTRACT.json [--json]`, `shape diff BASE.shape CURRENT.shape [--json]
  [--fail-on-drift]`. Exit 0 ok, 1 failed check or (with `--fail-on-drift`) drift, 2 usage or input error.
  `check` and `diff` fall back to their previous behaviour when the inputs are not profile artifacts, so the
  existing CLI tests are unchanged. `capture` keeps the old profile-to-`.shape` behaviour the old `profile`
  command had.
- `src/shape/api.py`: `check`, `diff` are the new functions. `shape.diff` is also the name of an old
  subpackage; importing `shape.diff` rebinds the attribute to the module, so `api.py` makes that module
  callable to keep `shape.diff(a, b)` working either way (regression test included). The clash disappears
  when P0-04 cuts the legacy package.

## Notes for the other lanes

- `Profile.summary()` layout: single table `{name, row_count, primary_key, columns: {<col>: {dtype,
  null_rate, cardinality, is_unique, is_primary_key, is_foreign_key, fk_ref_table, distribution, pattern,
  min, max, mean, std}}}`. Multi-table: `{name, row_count, tables: {<t>: <single-table summary>}, relationships}`.
- `CheckResult` and `DiffResult` are dataclasses with `.passed`/`.violations` and `.drifted`/`.changes` and
  `.to_dict()`.
- FK detection matches a column `<t>_id` to a table named exactly `<t>` (Spindle's rule).
