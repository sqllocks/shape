## What was built

- `scripts/build_pure_wheel.py`: writes `dist/sqllocks_shape-<version>-py3-none-any.whl` with the standard
  library only (a wheel is a zip plus `*.dist-info`). Contents: the `shape` package (`src/shape`) and
  `docs/specs` as `shape/schemas` (as pyproject's hatch force-include does), `LICENSE`, entry point
  `shape = shape.cli.main:main`. Reproducible (fixed timestamps).
- Wheel metadata is generated by the script, not taken from `pyproject.toml`: `Requires-Dist: numpy>=2.0,<3`
  and `pyarrow>=14`; no `cryptography`, `pydantic` or `typing-extensions` (`import shape` uses none of them);
  extras `delta`, `pandas`, `yaml`. `pyproject.toml` dependencies are unchanged (the stricter pins return in
  P0-05; §12.1 must be re-checked then).
- Self-checks (exit 1 on any failure): tag is `py3-none-any`; size below 28.6 MB (28,600,000 bytes);
  no compiled or native files (.so .pyd .dylib .dll .c .rs ...); `WHEEL` declares a pure wheel;
  the two requirements are declared and `cryptography`/`pydantic` are not; every `RECORD` hash matches.
- `--verify`: fresh venv holding only numpy, pyarrow, pandas, deltalake (+ pytest as the runner), installs the
  wheel, asserts `shape` is imported from site-packages and `cryptography` is absent, runs
  `tests/demo/core` against the installed copy from a scratch directory, and runs `shape --help`.
- `import shape` no longer needs `cryptography` (done in DM-01 with the lazy imports in
  `shape.security` and `shape.artifact.secure`; `tests/demo/core/test_wheel.py` asserts it with the
  package blocked).
- Version `0.9.0.dev1` in `pyproject.toml` and in `shape.__version__` (`src/shape/__init__.py`, one line;
  outside the L1 path list, but `shape version` would otherwise print a different version from the wheel).
