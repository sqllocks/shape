## What was built

- `src/shape/profile/reference/`: `model.py`, `readers.py`, `numerics.py`, `column.py`, `table.py` are the
  `benchmarks/vs_spindle/profile_1to1/port.py` port split into product modules (typed, no Spindle imports, no machine
  paths); `sources.py` resolves every source type; `profile.py` holds `Profile`, `profile()`, `save`, `load`.
- `shape.profile(source, *, name=None)` accepts a path or str (.csv, .parquet, .jsonl/.ndjson, Delta table
  directory, glob, directory of files), `pyarrow.Table`, `pandas.DataFrame`, or a dict of those (multi-table,
  runs FK detection). Delta needs `deltalake`; without it `ImportError` names the package.
- `Profile.to_dict()` is the same JSON shape that `benchmarks/vs_spindle/profile_1to1/spindle_dump.py` produces for
  Spindle's TableProfile / DatasetProfile. `Profile.summary()` is the small JSON-safe dict.
- Additions beyond the port so that lakehouse data does not crash the profiler: decimal columns are profiled
  as float64, `string_view` and time columns as strings (the port raised `NotImplementedError`).
- `import shape` no longer needs `cryptography`: `shape.security` re-exports its crypto names lazily and
  `shape.artifact.secure` imports crypto inside its two functions (touches two files outside the L1 list;
  §12.6 DM-03 requires the lazy import and `import shape` cannot work in the Spindle venv without it).
- `pyproject.toml`: only `[project.optional-dependencies]` changed (new `delta` and `pandas` extras;
  `dev` gains pandas, deltalake, twine).
- `benchmarks/vs_spindle/profile_1to1/verify.py`: new `--impl port|shape` option only (`shape` compares
  `shape.profile(...).to_dict()` with Spindle; the default stays the old port).

## Notes

- Multi-table FK detection follows Spindle's rule exactly: the column name is `<table>_id` and the table key
  must equal `<table>` (case-insensitive), so a `customer_id` column matches a table named `customer`,
  not `customers`.
- `shape.check` and `shape.diff` in this commit are still the pre-existing functions; DM-02 replaces them.
