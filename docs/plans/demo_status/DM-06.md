## Findings
- `from __future__ import annotations` breaks the SDK decorators (it needs real annotation objects); function_app.py must not use it.
- The SDK wraps decorated functions (runtime signature/annotations become the HTTP wrapper's). Tests unwrap with `inspect.unwrap(builder._function.get_user_function())` and read the declared return type from source.
- The fake Files client follows the documented `DataLakeDirectoryClient` calls (`get_file_client`, `get_file_properties().size`, `download_file().readall()`, `upload_data`); the real client's behaviour is unverified.
- The lakehouse connection alias is `shapeLakehouse` (edit LAKEHOUSE_ALIAS if the owner names it differently).
- `profileLakehouseTable` reads the first maxRows rows (TOP), not a random sample; `sampled: true` says so.
