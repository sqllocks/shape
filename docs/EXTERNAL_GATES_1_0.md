# Shape 1.0 External Evidence Gates
The reference implementation is feature-frozen, but these claims require external evidence before production claims should be made:
1. Run Arrow suites in the declared PyArrow environment.
2. Exercise Kafka/Event Hubs/Kinesis/Fabric/Snowflake/Databricks/SQL Server against real targets or maintained test containers.
3. Produce an independent second implementation for cross-language interoperability evidence.
4. Commission independent security and privacy assessment.
5. Use and verify a FIPS-validated crypto provider where required.
6. Obtain deployment-specific classified/CUI/regulated authorization.
7. Benchmark representative production hardware/workloads.
8. Finalize redistribution/licensing choices for production geographic reference bundles.
