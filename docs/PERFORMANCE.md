# Performance evidence

Read measurements with the machine and workload that produced them.

Status: available.

The [generated performance page](reference/performance.md) reads committed result data.
It reports only Shape measurements with a passing workload verifier and names the machine.
An empty result is a missing measurement, not a performance claim. This site publishes no
product comparisons or ratios.
