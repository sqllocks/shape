    Licensing¶

    Not legal advice.

    Counsel review is deferred by the Owner; this page does not provide blanket clearance of reference data. Owner decision, 2026-10-11.

    Understand the code licence and the notices attached to data.

    Status: available; Industry Profile Packs are coming.

    Code and contributions¶

    Shape code is MIT. Read LICENSE and the full third-party notices for bundled dependencies and reference data. Inbound contributions are under MIT with DCO sign-off; see Contributing.

    Your rows and profiles¶

    Generated data belongs to you. Shape claims no rights in it. Your own profiles stay yours. This statement does not remove obligations attached to reference data incorporated into an output or rights in the source rows. Review the notices and your source-data permissions. A safe capture is data minimisation, not anonymisation.

    Documentation diagrams¶

    The documentation site bundles Mermaid 11.17.2 from the npm distribution under MIT. Its bundle hash and source archive are in docs/assets/javascripts/mermaid-provenance.json. The Mermaid and installed dependency licence notices are preserved in docs/assets/javascripts/MERMAID_NOTICES.txt. scripts/vendor_docs_diagrams.py regenerates these assets from an install of the pinned package. No CDN request is needed to render diagrams.
