# fidelity_1to1: the fidelity report against the baseline comparator

P4-09 harness. `shape fidelity` must score a pair of datasets like the baseline's
`FidelityComparator` does (within 0.5 points per table; here the two agree to 1e-9).

```bash
source scripts/env.sh
"$SHAPE_VENV/bin/python" benchmarks/vs_refengine/fidelity_1to1/run.py [--scales small,medium]
"$REFENGINE_PY" benchmarks/vs_refengine/fidelity_1to1/golden.py --check
```

* `run.py` (Shape's venv) scores every pair twice, with the baseline's comparator in its own venv
  (`baseline_scores.py`, run with `$REFENGINE_PY`, loading the Parquet files with pandas as
  `domain_1to1/verify.py` does) and with `shape.generation.report` in process, then prints every
  table's two scores and the difference. Missing run directories are generated by
  `domain_1to1/generate.py`. Exit 0 only when every expectation below holds.
* Pairs: for each scale, retail with the baseline seed 42 as the reference and as the synthetic
  side Shape's output (seed 1042) and the baseline's seeds 43-46; and edge pairs built from seeds
  42 and 43.

| Pair | Expectation |
|---|---|
| retail pairs, `type_mismatch` | every table within 0.5 points |
| `missing_column` | the damaged table scores baseline x shared/reference columns (within 0.5), the column scores 0, other tables within 0.5 |
| `missing_table` | the table scores 0 and the report fails; other tables within 0.5 |
| `empty_reference` | every table scores 0 and the report fails |
| `unit_mismatch` | the baseline compares raw integer counts (a microsecond column against a nanosecond one scores badly); Shape compares nanoseconds, so its score equals the matching-units pair's |

  It also runs the `shape fidelity` command (exit codes, the alias, the three report formats).
* `golden.py` records the baseline comparator's scores for `golden_data.py`'s pairs (every branch of
  the scoring) in `fixtures/expected_scores.json`; `--check` fails if the file no longer equals the
  comparator's output. `tests/benchmarks/test_fidelity_1to1.py` checks Shape against that file and
  needs no baseline venv.

The baseline checkout is only read.
