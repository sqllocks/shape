# Contributing

Changes should preserve deterministic behavior, bounded-memory semantics where promised, sensitivity/provenance propagation and fail-closed handling of ambiguous or unsafe input. Add tests and requirement traceability for new normative behavior. Avoid mandatory network dependencies in core.

The 1.x promises are `docs/API_STABILITY.md`, `docs/CLI_STABILITY.md` and `docs/plugins/stability.md`; what 1.0 requires is `docs/V1_DONE.md`. Before proposing a feature, see `docs/NOT_BUILDING.md` for what the project has decided not to build.
