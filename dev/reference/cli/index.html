    shape doctor¶

    Stability: stable.

    usage: shape doctor [-h] [--json] [--fabric URI] [--broker URI] [--delta-table PATH]
                    [--timeout SECONDS] [--no-auth-check]
                    [--auth {cli,msi,spn,sql,device-code,fabric,kerberos}] [--tenant-id GUID]
                    [--client-id GUID] [--client-secret REF] [--sql-user NAME]
                    [--sql-password REF] [--keytab REF] [--principal NAME@REALM]

options:
  -h, --help            show this help message and exit
  --json                print the report as JSON

connectivity checks (each is off unless asked for):
  --fabric URI          check Fabric access: onelake://WORKSPACE/ITEM (OneLake reachable, sign-in,
                        workspace and item exist)
  --broker URI          check a broker: kafka://host:9092[,host2:9092]/topic or
                        eventhubs://NAMESPACE/HUB (DNS, TCP, TLS, sign-in; repeatable)
  --delta-table PATH    check a Delta table for deletion vectors and column mapping, which delta-
                        rs cannot read in a Python notebook
  --timeout SECONDS     per network step
  --no-auth-check       skip the sign-in step of --broker checks

authentication:
  --auth {cli,msi,spn,sql,device-code,fabric,kerberos}
                        how to sign in to Fabric / Azure: cli (az login, the default), msi
                        (managed identity), spn (service principal), sql (SQL login), device-code
                        (browser sign-in) or fabric (the Fabric notebook identity) or kerberos (a
                        keytab, for a SQL Server that takes Windows authentication only)
  --tenant-id GUID      Entra tenant (spn, device-code)
  --client-id GUID      Entra application (spn, device-code, msi)
  --client-secret REF   spn: the application secret, a credential reference: env://NAME,
                        file://PATH or kv://VAULT/SECRET
  --sql-user NAME       sql: the login name
  --sql-password REF    sql: the login's password, a credential reference: env://NAME, file://PATH
                        or kv://VAULT/SECRET
  --keytab REF          kerberos: the keytab, file://PATH (mode 600) or kv://VAULT/NAME (the
                        keytab base64-encoded); Shape runs kinit into a private cache that is
                        removed when the command ends
  --principal NAME@REALM
                        kerberos: the service principal

Exit codes:
  0   ok
  1   a required package is missing
  2   bad input: a missing or unreadable file, the wrong kind of file,
      or a bad argument

    shape plugins new¶

    Stability: stable.

    usage: shape plugins new [-h] --group GROUP [-o DIR] [--author TEXT] [--json] [--dry-run] NAME

Create a plugin package for one group of plugin API v1: pyproject.toml with the entry point, a
module that implements the group's protocol, a test that runs the conformance kit, a README and a
GitHub workflow. Nothing is written when the name is invalid, the group is unknown or the folder
is not empty.

positional arguments:
  NAME                  package name: lowercase letters, digits, hyphens

options:
  -h, --help            show this help message and exit
  --group GROUP         entry-point group, e.g. shape.sources
  -o DIR, --output DIR  folder to create it in (default: ./NAME)
  --author TEXT         author name for pyproject.toml
  --json                print the result as a shape-result
  --dry-run             read and check the inputs and print what the command would write or send,
                        then exit 0 (2 for invalid input); nothing is written and no connection is
                        opened

Exit codes:
  0   ok
  2   bad input: a missing or unreadable file, the wrong kind of file,
      or a bad argument

    shape plugins sign¶

    Stability: stable.

    usage: shape plugins sign [-h] --key KEY [-o OUT] [--passphrase-env VAR] [--passphrase-stdin]
                          [--json] [--dry-run]
                          WHEEL

Sign a plugin wheel with an Ed25519 key (needs the [sign] extra). The signature covers the wheel's
file list; `require_signature` in a plugin allow-list checks it at load.

positional arguments:
  WHEEL

options:
  -h, --help            show this help message and exit
  --key KEY             private key: a file, - (standard input), env://VAR, file://PATH or
                        kv://... (an encrypted key asks for its passphrase)
