    Quickstart¶

    Follow one short route from local rows to a reviewed baseline and generated data.

    Try it first, with no install: the Shape Playground replays a recorded Shape 0.9.3 session in your browser.

    Status: available.

    Run the local examples¶

    The examples below use disposable local files from this checkout. The example test environment sets SHAPE_DOCS_REPO, installs core and plugins from source, and prepares local services. Run each page in its own empty directory, in the order shown. Complete output appears beneath each command. Elapsed times, temporary paths, job IDs and generated signing keys vary; the harness validates those runtime fields and compares the remaining output exactly.

    python "$SHAPE_DOCS_REPO/scripts/docs_example_setup.py" QUICKSTART
    Output (exit 0) 
    Prepared local fixtures for QUICKSTART

    Start with Your first profile. Its tested commands create 21,750 retail rows across nine tables, profile the folder and save a .shape file. The walkthrough also shows the dataset safe-validator refusal. You can open the HTML file locally; it needs no account.

    Next, write a contract. You state that the id must be unique and non-null and that an amount cannot be negative. Run the check against the saved profile and read the observed output. A zero exit code means those rules pass; an unavailable rule is not a pass.

    Then commit a shape and catch drift. Keep the profile in an isolated Git repository, change the input, profile again and compare the artifacts. The example includes the expected nonzero drift exit code. Review a change before accepting a baseline.

    Finally, generate dev data from a profile. Use an explicit format and output directory. Generation from a profile is available and is being hardened. Inspect the rows instead of assuming every property of the original data is reproduced.
