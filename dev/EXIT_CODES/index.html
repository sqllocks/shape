    Exit codes¶

    Status: available.

    Every shape command ends with one of the codes below. The classes are the same everywhere:

    Code Class
    0 ok
    1 a check failed, drift was found, a signature or leak scan failed
    2 bad input: a missing or unreadable file, the wrong kind of file, a bad argument
    3 and above the command's own verdict (a failed certificate, contract or compatibility check)

    Writing a report (--junit, --sarif, --json) never changes a command's exit code, and a command's --help ends with the same table. shape itself exits 2 for an argument that does not parse, and 130 when a scale run is interrupted. See docs/CLI.md and docs/CI.md.
